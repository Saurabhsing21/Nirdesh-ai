# Response cue assets

`neutral-ack.wav` is a short, non-semantic development cue (mono PCM, 24 kHz)
preloaded into the existing browser `AudioContext`. Every supported language
currently maps to this neutral cue so the application never plays a confident
wrong-language phrase.

The checked-in clip was generated locally with a macOS system voice for this
prototype. Replace it with a product-approved, licensed recording—ideally the
same voice family and loudness as the configured Bulbul speaker—before public
distribution. Keep the filename and short duration so replacement does not
change the protocol or playback policy.
